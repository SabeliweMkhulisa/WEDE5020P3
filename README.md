# WEDE5020P3
Crowned Ember Restaurant Website
1. Navigation and Layout
I structured the website using a header with a logo and navigation menu. 
Users can easily navigate between pages, Home, About Us, Menu, Awards, Contact, and Enquiry. 
For mobile users, I implemented a hamburger menu that expands and collapses, making navigation accessible on smaller screens.

2. Home Page Interactivity
On the home page, I included a slideshow combining video and images to showcase the restaurant ambiance and dishes.
 Users can view additional static images below the slideshow.
 I also implemented a lightbox feature, so when users click an image,
 it enlarges for a closer look, and they can browse through all images using next/previous controls.

3. Animated Headings and Effects
I added typing animations for headings using JavaScript. 
For example, the main headings “Welcome to Crowned Ember” or “Enquiry Form” appear letter by 
letter with a blinking cursor, making the page visually engaging. I also included shimmer effects on headings and footer text
 to enhance the aesthetic appeal.

4. Scroll-to-Top Button
I created a floating “UP” button that appears when users scroll past a certain point. 
When clicked, it smoothly scrolls the page back to the top, improving navigation on long pages.

5. Menu and Awards Pages
I used JavaScript to make the menu and awards images responsive. 
On mobile, images resize or are grouped into horizontal scroll containers, 
allowing users to swipe through photos easily. Lists of menu items or awards are animated to fade in 
sequentially, guiding the user’s attention and improving readability.

6. Forms (Contact and Enquiry Pages)
I implemented form validation using JavaScript:

The name field only accepts letters.

The email field must follow a valid format.

I used EmailJS to handle form submissions, sending the user’s enquiry directly to the restaurant’s email.
 Success and error messages appear dynamically on the page, providing immediate feedback.

7. Responsive and Accessible Design
I ensured the website adapts to all screen sizes using responsive CSS, flexible image sizing, 
and media queries. I also used semantic HTML (header, nav, main, footer)
 and alt text for images to improve accessibility and allow search engines to index the content properly.

8. User Engagement
Through interactive elements—animations, slideshows, hover effects, and 
responsive images. I increased user engagement. 
Visitors can explore menus, awards, and gallery images intuitively while 
enjoying a visually appealing experience.

In summary, the website combines structured content, interactive features, responsive design, 
and form functionality to provide an engaging,
 accessible, and easy-to-navigate experience for visitors on any device.
